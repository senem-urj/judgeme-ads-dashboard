# Judge.me Shopify Ads Analysis Dashboard

Interactive Streamlit dashboard for analyzing Judge.me Shopify App Store advertising performance.

## Analysis Period
August 21, 2025 - February 18, 2026

## Focus
Keyword Discovery for Install Growth

## Dashboard Sections
- **Executive Summary** - Key metrics and findings
- **Campaign Performance** - All 4 campaigns comparison
- **Keyword Analysis** - Complete keyword metrics
- **New Keywords** - 25 keyword recommendations with bids
- **Keywords to Pause** - Underperforming keywords
- **Bid Recommendations** - Optimization suggestions
- **Search Term Opportunities** - High-potential search terms
- **Negative Keywords** - Current strategy
- **Action Checklist** - Prioritized tasks

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
